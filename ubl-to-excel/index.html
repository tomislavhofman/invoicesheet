Convert UBL and Peppol invoice XML to Excel

    What you get

    The Excel file has three sheets:

    • Invoices: file, format, type (invoice or credit note), number, issue and due date, currency, seller and buyer with VAT IDs and country, buyer and order reference, net, VAT, gross, prepaid, amount due, IBAN, payment reference, number of lines and an arithmetic check.
    • Line items: invoice number, line number, item name, description, item number, quantity, unit, unit price, net amount, VAT category and rate.
    • VAT breakdown: one row per VAT category and rate per invoice, with taxable amount and VAT amount.

    The same data is available as CSV (invoices or line items) for import into accounting software.

    How to convert

    1. Drop your .xml files above, or a ZIP exported from your access point or accounting inbox. PDFs with embedded ZUGFeRD or Factur-X XML work too.
    2. Check the table: totals are recalculated and mismatches are flagged.
    3. Click “Download Excel” or one of the CSV buttons.

    Why not Excel's own XML import?

    A UBL invoice is a tree: one header, several parties, any number of lines, any number of VAT subtotals, each in its own namespace (cac:, cbc:). Excel's XML import either refuses the file or flattens the tree into repeated rows, where the header values are duplicated for every line and every VAT rate. Summing a column then gives the wrong total. InvoiceSheet maps each EN 16931 business term to its own column instead, so every sheet is a clean table you can filter, pivot or import.

    Private by design

    The files are parsed by JavaScript in your browser. Nothing is uploaded, so you can convert supplier invoices without sending them to a third party.

    Building your own mapping? The EN 16931 field reference lists the UBL and CII XPath of every business term.

    Questions

    Does it handle credit notes?

    Yes. UBL CreditNote documents are recognised, marked as credit notes and subtracted in the table totals. In the export they keep the sign used in the document.

    Which decimal separator does the CSV use?

    It follows the page language: the English page uses a comma separator and a decimal point; the German, French, Dutch and Croatian pages use a semicolon and a decimal comma, which is what Excel expects in those countries.

    Is there a file limit?

    Viewing is unlimited. Converting hundreds of files at once works; the practical limit is your browser memory.

    Does it validate Peppol invoices?

    It checks the arithmetic (net + VAT = gross, lines add up, amount due) and flags mismatches. It does not run the full Peppol schematron rules.
